## ✅ 체크리스트
Merge 전에 아래 항목을 확인하세요.

- [ ] 관련 이슈를 연결했나요?
- [ ] 로컬 환경에서 테스트를 완료했나요?
- [ ] 테스트 내역을 작성 했나요?
- [ ] 코드 리뷰를 요청했나요?
- [ ] 필요한 문서를 업데이트했나요?

---

## 📌 추가 사항
추가적으로 공유할 사항이나 리뷰어가 알아야 할 내용을 작성하세요.

- (예: '이 로직은 추후 리팩토링이 필요합니다.')
- (예: 'C 기능은 다음 Sprint에 구현 예정입니다.')
